## Originality rules

1. Reproduce general technical behaviors with original geometry, audio, art direction, layouts and wording.
2. Never treat publicly loadable JS/GLB/texture files as freely redistributable source or assets.
3. Keep rights basis distinct from visual originality: both must pass before publication.
4. Preserve run IDs, version labels, approved asset provenance and test reports. No checksum process is used.
5. Do not modify APPROVED CCOS film/canon assets for a web experiment without authorization.
6. Avoid use of Igloo brand names in the public-facing experience except factual research and attribution.

## Proposed source classification

- DEVELOPER-SUPPORTED: disclosed techniques and named tools (per case study).
- VERIFIED_REPO_METADATA: accounts, public descriptions and licenses inspected through GitHub.
- DERIVED: implementation abstractions (GPU-point interpolation, camera arc, HTML/WebGL split).
- AUGMENTED: accessibility, fallback, performance telemetry, versioned project data and modularization.
- TEST_RESULT: retain only outcomes actually observed locally; see verification report.
